# Historial de versiones

## ReservaYa v1.0

Funcionalidades:

- Registro.
- Login.

Problemas conocidos corregidos en la nueva versión:

- Login aceptaba contraseña incorrecta.
- Contraseña menor a 8 caracteres.
- Problemas de validación del registro.

## ReservaYa v2.0

Nuevas funcionalidades:

- Agendar hora.
- Ver horas agendadas.

Esta versión contiene nuevos defectos intencionales para actividades educativas de testing.
